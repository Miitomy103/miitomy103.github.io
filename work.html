Information

  • 制作人数：個人制作
  • 担当：企画 / 実装 / UI
  • 使用技術：Unity / C# / Cinemachine

Implemented Features

  • プレイヤー移動システム
  • 敵AI
  • ロックオンカメラ
  • UIアニメーション
  • HPシステム

Point
